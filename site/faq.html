Help

Questions and known issues

Short answers first, then the things that are still rough. If something is missing, the issue tracker is the place to ask.

Getting started

Is Suura free?

Yes. Suura is MIT-licensed and free, with no account, no paid tier and no advertising. The source is on GitHub.

Which Windows versions does it run on?

Windows 10 and Windows 11, 64-bit. It installs for your user only, into %LOCALAPPDATA%\Programs\Suura, so it never asks for administrator rights.

Why does SmartScreen warn about the installer?

The build is not code-signed yet, so Windows shows "Windows protected your PC" for a new file it has not seen before. Choose More info → Run anyway. The checksum in SHA256SUMS.txt matches the file you downloaded, so you can verify it yourself before running it.

Does it work offline?

Your own files and anything you saved or cached play with no connection. YouTube, lyrics, tags and covers need one, because each of those is a request to a server.

What happens to my files?

Suura indexes the folders you choose and never moves or renames anything. It writes into a file only when you edit its tags or lyrics, save a stream, or use To phone — and tag and lyric edits keep a backup first. Playlists live in Suura's own database, not in your music folder.

YouTube and streaming

Why does playback need yt-dlp?

Suura resolves and streams YouTube itself, and yt-dlp is the piece that does it. Suura offers to download it the first time you paste a link, and updates it only when you ask. Nothing is installed until a YouTube feature needs it.

YouTube says it wants to confirm I'm not a bot. What now?

That check comes from YouTube, not from Suura. Try again in a few minutes; if it keeps happening, Settings → Streaming explains the optional PO Token provider, which is a separate program that helps with exactly this. The optional cookie fallback can also help if you have a YouTube session in a browser on this computer.

Do saved tracks keep working if a video is taken down?

Yes. A saved track is a real file in your Music folder with its tags and cover, and it plays without YouTube. A track you only cached may be evicted when the cache fills; saving it makes it permanent.

How do I get a playlist onto my phone?

Open a playlist and press To phone. Suura copies the local files into a folder you pick, inside a folder named after the playlist, and writes an .m3u8 beside them with plain file names. Copy that folder to the phone; PowerAmp and most players read it as-is.

Updates and data

How do updates work?

Suura checks its update feed about twenty seconds after launch and at most once a day. Settings → About shows the last check and offers Check now, then Download update and Restart and install. Your library, playlists and settings are kept.

What does Suura send over the network?

The update check is the only request it makes on its own; everything else waits for a button. The privacy statement lists every host and what each one receives.

Where is my library stored? Can I move it?

The audio stays in your folders. Suura's database, caches, engine binaries and logs live in %APPDATA%\Suura. Settings → Misc has Back up now and Restore from backup, plus an export of the library as CSV. A restored database matches its files again on the next scan.

If I uninstall, is my data deleted?

Only if you say so. The uninstaller asks, and the default answer keeps Suura's data folder for a later reinstall. Your music is never deleted, including anything Suura saved into Music\Suura.

Is there an Android or iOS app?

No. Suura is a Windows desktop app. Getting music onto a phone means copying files — the To phone button does the packing — and Android is not planned unless enough people ask for it.

Known issues

These are known today. Anything here is a bug or a deliberate gap, not a surprise:

  • The installer is unsigned. Windows SmartScreen warns until code signing is in place. This is the same file and the same app; verify the checksum if you want certainty.
  • Playlists are not associated with Suura. Double-clicking an .m3u or .m3u8 in Explorer does not open the app. Import the file from the Playlists view instead.
  • Gapless playback is in; crossfade is not. Tracks run into each other without a gap, but there is no overlap or fade between them.
  • YouTube playback can be interrupted by YouTube. A bot check, a removed video or a changed player can stop a stream until the engine updates. Nothing in the app can promise otherwise.
  • The PO Token provider is not bundled. It is separate software you install and run; Settings only points Suura at it.
  • Windows only, 64-bit. There is no portable build, no 32-bit build and no macOS or Linux build.

Reporting a problem

Open an issue at github.com/alphaq0099/Suura/issues. Settings → About can Copy diagnostics or Save diagnostics for you; both contain local file paths, so read them before you paste. Crash reports are off by default — if you want one, turn it on in Settings → Misc before the crash and attach the file yourself.
